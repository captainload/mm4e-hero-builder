# Mutants & Masterminds 4th Edition (4E) Hero Builder

A modern, comprehensive web-based character builder and manager for the **Mutants & Masterminds 4th Edition** tabletop superhero roleplaying game.

---

### 🚀 Run the Program Online:
👉 **[Launch Mutants & Masterminds 4E Hero Builder](https://captainload.github.io/mm4e-hero-builder/)**

*(No installation required — runs directly in any modern desktop or mobile web browser!)*

---

## ⚡ Features
- **Full Ruleset Accuracy**: Faithful to Mutants & Masterminds 4E rules with unabridged modifier and power descriptions.
- **Dynamic Power Point Accounting**: Real-time PP tracking with visual warnings and confirmation safeguards when exceeding budget limits.
- **Power Configuration Suite**: Comprehensive configurator for all powers, effects, modifiers, sensory profiles, and condition tracks.
- **Character Forms & Alts**: Complete support for Alternate Forms, Minions, and Mecha companions.
- **Local File & Browser Storage**: Save and load character sheets in `.mm4e` format using native OS file pickers or download fallbacks.
- **Print & Export Ready**: Clean printable character sheets and statblock summaries.
- **Automatic & Manual Update Checks**: Built-in update engine with one-click app reload for local offline users.

---

## 💻 Running Locally (Offline)
1. Download the latest release from the **[Releases](https://github.com/captainload/mm4e-hero-builder/releases)** page or click **Code > Download ZIP**.
2. Extract the ZIP file to any folder on your computer.
3. Double-click **`Launch Hero Builder.bat`** (or open **`index.html`** in any web browser).
4. No web server, Node.js, or internet connection required for offline use.
